# 🚀 System Monitoring Dashboard

## 📜 Description

A modern, **real-time system monitoring dashboard** designed for keeping track of critical system metrics. Built with **React** and styled using **Tailwind CSS**, this dashboard provides a clean, responsive interface for monitoring system health, displaying active alerts, and visualizing real-time metrics.

With **Recharts** for data visualization, this dashboard allows users to toggle between different views (Grid/List) and provides detailed status updates on system performance. It's perfect for monitoring and keeping track of system alerts, metrics, and activity in real-time.

## ✨ Features

- 📊 **Real-time System Monitoring**: View live metrics and monitor system performance with detailed charts.
- 📱 **Fully Responsive**: Optimized for both desktop and mobile devices for seamless access.
- 🔄 **View Toggle**: Switch between **Grid** and **List** views to organize system metrics as per your preference.
- 🚨 **Active Alerts**: Easily track critical, warning, and info alerts in a dedicated section.
- 🟢 **Status Summary**: Displays system health with real-time status updates—Normal, Warning, and Critical.
- 📉 **Data Visualization**: Charts and graphs powered by **Recharts** to visually represent system data.
- ⚡ **Instant Updates**: Live system activity updates and alert notifications for immediate action.

## 🛠 Tech Stack

- **React** - Front-end framework for building user interfaces.
- **Tailwind CSS** - Utility-first CSS framework for styling and responsive design.
- **Recharts** - Charting library for rendering real-time data and metrics.
- **React Icons** - Scalable and customizable icons for a smooth user interface.

## 🧑‍💻 Usage

### 1. 📊 **View Toggle**
- **Grid View**: Display metrics in a grid format for an organized and compact layout.
- **List View**: Switch to a list layout for a more detailed, linear display of system metrics.

> Toggle between these views to adjust the layout based on your preference. It's perfect for both overview and detailed inspection.

---

### 2. 🟢 **Status Summary**
Stay on top of your system's health with real-time status indicators:
- **Normal**: Shows the number of systems operating without issues. 🟢
- **Warning**: Indicates the systems with potential issues or warnings. ⚠️
- **Critical**: Highlights systems with major issues that need immediate attention. 🚨

> The **Status Summary** section provides a quick overview of the overall health of the system, helping you identify problems at a glance.

---

### 3. 🚨 **Active Alerts**
Monitor all active alerts that require attention:
- **Critical Alerts**: Immediate actions are needed to address severe issues. 🚨
- **Warning Alerts**: Issues that should be monitored closely but aren't critical. ⚠️
- **Informational Alerts**: Updates about system activity or status that don't require immediate action. 📩

> Each alert category shows the number of unresolved issues, making it easier to prioritize response.

---

### 4. 📈 **Current Activity Chart**
- **Live Activity**: This section visualizes real-time system activity with a line chart, updated continuously.
- **Trends**: Watch for performance trends, anomalies, or any sudden spikes in system activity.

> Stay informed about the current state of the system with real-time updates on activities and performance metrics.

---

### 5. 🔔 **Notifications**
Receive real-time notifications for new system alerts:
- **Alert Count**: Get notified about the number of unresolved critical, warning, and informational alerts.
- **Interactive Alerts**: Click on notifications to jump directly to the relevant alert details.

> Notifications ensure you're always aware of new issues or updates, without needing to constantly check the dashboard.
